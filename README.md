# Inventory Management System

## Overview
The Inventory Management System is a full-stack web application developed using Spring Boot and Thymeleaf. It helps users manage products and inventory in a simple and efficient way.

## Features
- Secure Login System
- Product Management (Add, Update, Delete, View)
- Stock Management
- Search Products
- Dashboard
- Responsive User Interface
- MySQL Database Integration

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- MySQL
- HTML
- CSS
- Bootstrap
- Maven
- Eclipse IDE
- Git & GitHub

## Project Structure
- Controller
- Model
- Repository
- Service
- Templates
- Static Resources

## Installation
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Create a MySQL database.
4. Update the database details in `application.properties`.
5. Run the Spring Boot application.
6. Open the application in your browser.
